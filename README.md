<a name="install"></a>
<div align="center"><img src="images/readme/install.svg" alt="How to install" width="100%"></div>

1. In game, type `/xlsettings` and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste this URL from [Will-o-Plugins](https://github.com/NeonGhostCinnamon/WillOPlugins) (it has all of my plugins), click **+**, tick **Enabled** and click **Save and Close**:

   ```
   https://raw.githubusercontent.com/NeonGhostCinnamon/WillOPlugins/HEAD/repo.json
   ```

3. Type `/xlplugins`, search for **Will-o-Patchwisp** and install it.
4. Open it any time with **`/patchwisp`**.

<br>

<div align="center"><img src="images/readme/notes.svg" alt="Extra Information" width="100%"></div>

- The one-click **Update** buttons use Dalamud's own internal updater. That isn't official Dalamud API, so if a future Dalamud version changes it, the buttons fall back to opening Dalamud's plugin installer on the updates page.
- GitHub lookups only happen when you open a card that has no changelog, and the results are cached (GitHub allows about 60 lookups per hour without an account).
