## Usage

I've created these plugins for my own use, but figured I might as well release them on GitHub. They're not as fancy as "proper" plugins, but I hope you can make good use of them too!

## Description

Will-o-Patchwisp shows you what changed whenever your Dalamud plugins update, and which updates are waiting, so you never miss a changelog again.

<details>
<summary><b>More details and settings</b></summary>
<br>

- **Recent**: every update it notices, grouped by day, with the changelog of each version.
- **Available**: updates you haven't installed yet. "Check for updates" lists them so you can pick which to install, or update everything at once. (Will-o-Patchwisp itself is updated through Dalamud's installer.)
- **All plugins**: the changelog of every plugin you have, plus up to 10 older updates (5 more at a time).
- No changelog in the plugin? It looks for release notes or recent commits on GitHub, or offers a button to the plugin list it came from. Links in changelogs are clickable.
- **Settings**: open the window after updates · print updates in chat (pick the channel) · track new installs · check repositories on startup · how much history to keep · an ignore list · dark, light or Dalamud theme.

</details>

## How to install

1. In game, type `/xlsettings` and open the **Experimental** tab.
2. Under **Custom Plugin Repositories**, paste this URL, click **+**, tick **Enabled** and click **Save and Close**:

   ```
   https://raw.githubusercontent.com/NeonGhostCinnamon/WillOPlugins/HEAD/repo.json
   ```

3. Type `/xlplugins`, search for **Will-o-Patchwisp** and install it.
4. Open it any time with `/patchwisp`.
